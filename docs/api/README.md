# API reference

These guides describe the services used by the examples.

| Interface | Purpose |
| --- | --- |
| [WebSocket gateway](ws-gateway.md) | Submit orders and receive packed Cap'n Proto replies |
| [TCP order gateway](tcp-orders.md) | Exchange reference data, orders, and replies over the shared TCP transport |
| [TCP market data feed](tcp-market-data.md) | Receive streamed price field/value updates |
| [REST market data feed](rest-market-data.md) | Query the latest price fields for securities |
| [REST reference data feed](rest-reference.md) | Retrieve accounts, venues, securities, positions, and limits |
